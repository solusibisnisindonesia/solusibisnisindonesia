# SolusiBisnis Indonesia

Kami mengembangkan prototipe AI berbahasa Indonesia untuk pekerjaan sehari-hari UMKM. Fokus kami adalah alur yang mudah diikuti dan hasil yang bisa ditinjau sebelum dipakai.

## Proyek unggulan · Kantor Sobis

[Kantor Sobis](https://github.com/solusibisnisindonesia/kantor-sobis) adalah ruang kerja lokal untuk tim agen AI. Beri arahan kepada Sobis, lihat pembagian tugas kepada spesialis, dan tinjau hasil di papan tugas. Usulan memori digunakan setelah Anda menyetujuinya.

[**Coba demo simulasi tanpa kunci API**](https://github.com/solusibisnisindonesia/kantor-sobis#jalankan-demo-di-windows)
